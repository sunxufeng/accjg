# 共创录 · 初中AI素养修行RPG —— 设计文档（DESIGN）

> 版本：v1.0 ｜ 日期：2026-08-13

---

## 1. 信息架构（IA）

```
App
├─ Onboarding（创角卷轴：道号 + 门派选择）
├─ Main World（水墨仪表盘，底部导航）
│   ├─ 修行地图  → RPG 像素世界（Canvas 引擎）
│   ├─ 任务      → 修行任务列表（日常/主线/支线）
│   ├─ 技能      → 四维技能树
│   ├─ 每日一问  → 卷轴答题
│   ├─ 典籍      → 典籍阅览 + 思辨题
│   ├─ 文献      → 文献库卡片
│   ├─ 共创      → 章节进度 + 排行榜
│   └─ 成就      → 统计 + 成就卡
├─ Realm（境界突破动画）
└─ Settings（主题 / 音效 / 重置）
```

## 3. 视觉规范（Visual System）

### 3.1 双主题
- **水墨主题（默认）**：宣纸底 `#f5f0e6`/`#faf7f0`，墨色 `#1a1a1a`→`#bbb`，朱砂 `#c23a2b`，石青 `#2c5f7c`，赭石 `#b8860b`，金 `#c9a227`。字体：Ma Shan Zheng（标题）、ZCOOL XiaoWei、Noto Serif SC。
- **像素夜主题（扩展）**：深底 `#1b1b2a`，草绿 `#4a6741`，路径 `#8a8677`，水蓝 `#2a4a6c`，袍红 `#c84a3a`，金 `#d4a840`。字体：SimHei/等宽，`image-rendering: pixelated`，扫描线。

### 3.2 统一装饰元素
- 印章（朱红方框 + 白字）、卷轴木轴、毛笔按钮（hover 墨晕扩散）、竹节标题条。
- 动效：卷轴展开（transform scaleY）、印章盖下（scale+opacity）、境界突破（金光 + 震动）。

### 3.3 响应式
- 桌面 ≥1024：地图 1280×1024 自适应缩放；仪表盘双栏。
- 移动 <768：单栏，底部固定 tab，左下虚拟摇杆，弹窗全屏化。

## 4. 交互流程（关键状态机）

```
[未创角] --提交--> [主世界]
[主世界] --点修行地图--> [RPG]
[RPG] --靠近+交互--> [对话/答题弹窗] --完成--> [主世界/奖励]
[主世界] --每日一问--> [答题] --提交--> [反馈+连续+1]
[修为≥阈值] --> [境界突破动画] --> [主世界(新境界)]
```

## 5. 数据结构（Schema，localStorage）

```ts
GameState {
  profile:   { name, sect, avatarSeed, createdAt }
  realm:     { level, exp, expToNext }          // 境界等级与修为
  spirit:    number                             // 灵气
  insight:   number                             // 顿悟
  streak:    { days, lastDate }                 // 连续修行
  tasks:     { [id]: 'accepted'|'done'|'claimed' }
  skills:    { [nodeId]: boolean }
  reading:   { [id]: boolean }
  daily:     { date, answered, correct }
  achievements: { [id]: boolean }
  settings:  { theme, sound }
}
```

门派：`算法门 / 数据宗 / 伦理阁 / 应用派`，各自 startingBonus（修为/灵气/某维度加成）。

---

## 6. 内容数据规划（data.js）

- **题目**：≥20 道，覆盖 认知/数据/伦理/应用 四维度，含讲解与"经典出处"。
- **典籍**：≥4 篇（仿古文写 AI 科普），各带 1 道思辨题。
- **文献库**：≥6 条，带类型标签与摘要。
- **技能树**：4 维 × 4~5 节点。
- **NPC/参悟点**：地图 ≥6 个交互点。
- **成就**：≥8 个。

---

## 7. 动效与无障碍

- 尊重 `prefers-reduced-motion`：关闭大幅动画。
- 关键操作有音效开关（WebAudio 合成，无需音频文件）。
- 文字对比度满足可读；提供主题切换。
