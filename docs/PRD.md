# 共创录 · AI素养修行RPG —— 产品需求文档（PRD）

> 版本：v1.0 ｜ 作者：产品协同助手 ｜ 日期：2026-08-13
> 参考原型：共享网页「共创录—AI素养游研网」（CSS 框架，仅含视觉骨架，无业务逻辑与内容）
> 本文档在原型基础上**补全真实玩法与内容**，并新增若干扩展功能。

---

## 1. 背景（Background）

学生阶段是培养「AI 素养」的关键窗口期。学生需要理解 AI 是什么、能做什么、有什么边界与风险，并学会负责任地使用 AI 工具。传统说教式教学枯燥、难入门。

参考原型以「水墨修仙 + 像素 RPG」的混搭美学，把 AI 素养学习包装成「修行」体验，概念新颖但**仅提供了视觉骨架**（CSS 类名、配色、字体、布局），没有任何可玩逻辑和教学内容。

本项目目标：基于该视觉框架，**还原并扩展为一款真正可玩、内容充实、画面精美**的网页小游戏，让学生在「打怪升级」的体验中潜移默化地建立 AI 素养。

## 2. 目标（Goals）

| 目标 | 说明 | 衡量 |
| --- | --- | --- |
| G1 可玩性 | 提供完整闭环：创角 → 修行 → 答题 → 升级 → 成就 | 玩家可从不跳转地走完一局 |
| G2 内容充实 | 内置 ≥20 道 AI 素养题目、≥6 篇典籍/文献、≥4 门派 | 内容数据可枚举 |

| G5 零部署门槛 | 纯静态前端，任意静态服务器即可托管 | 域名可直访 |

## 3. 用户故事（User Stories）

- 作为**学生**，我想创建自己的修行人（道号+门派），获得代入感。
- 作为**玩家**，我想在像素地图里走动、和 NPC 对话、到参悟点答题，像玩游戏一样学 AI。
- 作为**学习者**，我想通过「每日一问」每天学一个知识点，并看讲解与经典出处。
- 作为**收集控**，我想解锁技能树、读完典籍、点亮成就，获得成长反馈。
- 作为**老师/家长**，我希望内容准确、正向，且能在排行榜看到学习进度。

## 4. 功能清单（Feature List，EARS 表述）

### 4.1 创角与门派
- **[Ubiquitous]** 系统应在首次进入时强制引导玩家完成创角（道号、门派），否则不可进入主世界。
- **[Event-driven]** 当玩家选择某门派并提交时，系统应生成对应配色的像素头像并写入存档。
- **[Optional]** 若玩家留空道号，系统应自动赋予默认道号「无名」。

### 4.2 像素 RPG 世界（扩展核心）
- **[Event-driven]** 当玩家按下方向键/WASD 时，系统应使修行人按瓦片移动并播放行走动画。
- **[Unwanted]** 若修行人前方为水域/建筑（不可通行瓦片），系统应阻止移动（碰撞）。
- **[Event-driven]** 当修行人相邻于 NPC / 参悟点并按下交互键（空格/E）时，系统应弹出对应面板。
- **[State-driven]** 当处于 RPG 模式时，系统应隐藏水墨导航栏，显示 HUD（道号、境界、灵气）与操作提示。

### 4.3 修行任务
- **[Event-driven]** 当玩家点击「领取」已完成任务奖励时，系统应发放修为与灵气并更新进度。
- **[State-driven]** 当任务处于「可前往」状态时，系统应提供「前往」按钮跳转对应地图/答题。

### 4.4 技能树
- **[Event-driven]** 当玩家消耗足够灵气解锁某技能节点时，系统应点亮该节点并记录被动加成。
- **[Unwanted]** 若灵气不足，系统应提示并禁止解锁。

### 4.5 每日一问
- **[Ubiquitous]** 系统应每天提供 1 道 AI 素养题，按本地日期判断刷新。
- **[Event-driven]** 当玩家提交答案时，系统应判定对错，展示讲解、经典出处与连续修行天数 +1。
- **[Unwanted]** 若当天已答，系统应直接展示「今日已修行」并允许复习。

### 4.6 典籍阅览与文献库
- **[Event-driven]** 当玩家读完一篇典籍并作答思辨题，系统应发放顿悟并标记已读。
- **[Event-driven]** 当玩家打开文献库条目，系统应展示摘要、类型标签与出处。

### 4.7 共创 / 排行榜（扩展）
- **[Event-driven]** 当玩家修为变化时，系统应实时重算其在排行榜中的位置并将玩家行高亮。
- **[Ubiquitous]** 系统应展示共创章节进度、弟子总数、灵气总量等社群概览（Mock 数据 + 真实玩家贡献）。

### 4.8 成就与境界
- **[Event-driven]** 当玩家达成某成就条件（如连续修行 7 天），系统应点亮成就卡并弹出祝贺。
- **[State-driven]** 当修为达到阈值时，系统应提升境界并播放突破动画。

### 4.9 存档与设置（扩展）
- **[Ubiquitous]** 系统应将游戏状态持久化到 localStorage，刷新/重开不丢进度。
- **[Event-driven]** 当玩家切换主题（水墨/像素夜）或开关音效时，系统应保存偏好。
- **[Unwanted]** 若存档损坏，系统应重置为创角流程而不崩溃。

### 4.10 论道 mini-game（扩展·创造）
- **[Event-driven]** 当玩家在地图进入「论道台」，系统应提供提示词创作挑战，按清晰度/完整度评分并发放灵气。

## 5. 流程说明（Flow）

1. 首访 → 创角卷轴（道号 + 门派）→ 进入主世界（水墨仪表盘）。
2. 主世界底部导航：修行地图 / 任务 / 技能 / 每日一问 / 典籍 / 文献 / 共创 / 成就。
3. 点击「修行地图」→ 进入像素 RPG → 走动到参悟点 → 答题/对话 → 获得修为灵气。
4. 任务页接取任务 → 前往地图完成 → 领奖。
5. 技能页用灵气解锁节点 → 获得被动。
6. 每日一问每日一题 → 累计连续天数。
7. 修为达阈值 → 境界突破 → 解锁更高阶内容/排行榜名次上升。

---

## 6. 交互说明（Interaction）

- 桌面：方向键/WASD 移动；空格/E 交互；ESC 开菜单；点击导航切换视图。
- 移动端：左下虚拟摇杆移动；靠近交互点自动弹出提示，点按交互；底部 tab 导航。
- 所有弹窗为卷轴/木牌风格，支持点击遮罩或关闭按钮退出。

---

## 7. 数据指标（Metrics）

- DAU / 7 日留存（localStorage 标记活跃日）。
- 人均每日答题数、正确率。
- 典籍读完率、技能解锁率、成就点亮率。
- 平均境界进度。

---

## 8. 验收标准（Acceptance Criteria）

- [ ] 首次进入强制创角，可生成头像并进入主世界。
- [ ] 像素地图可移动、有碰撞、NPC/参悟点可交互。
- [ ] 每日一问按日期刷新，提交后给讲解与出处。
- [ ] 任务可接取、完成、领奖，数据与 HUD 同步。
- [ ] 技能树可解锁并记被动；灵气不足被拦截。
- [ ] 典籍/文献可阅读并标记。
- [ ] 排行榜含真实玩家且高亮；成就可点亮；境界可突破。
- [ ] 刷新后进度不丢失；主题/音效偏好保存。
- [ ] 桌面与移动端均可用，视觉走查通过。
- [ ] 部署到 accjg.areteailab.com 可公网访问。
