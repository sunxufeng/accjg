# 共创录 · AI素养修行RPG

一款「水墨修仙 × 像素 RPG」风格的 AI 素养修行网页小游戏。在打怪升级的体验中，潜移默化地建立 AI 素养（原理认知 / 数据素养 / 伦理安全 / 应用创造）。

> 参考原型：共享网页「共创录—AI素养游研网」（仅 CSS 视觉骨架），本项目在原型基础上补全真实玩法与内容，并新增多项扩展功能。

## 玩法

- **创角**：取名道号、择一门派（算法门 / 数据宗 / 伦理阁 / 应用派），生成像素头像。
- **修行地图**：像素 RPG 世界，方向键 / WASD 移动，走近参悟点 / NPC 按空格交互。
- **每日一问**：每天一题，提交后给讲解与经典出处，累计连续修行天数。
- **典籍阅览 / 文献库**：读古文思 AI，作答思辨；延伸文献卡片。
- **技能树**：四维技能，消耗灵气点亮，获得修行加成。
- **论道台**（扩展）：提示词创作挑战，按清晰度 / 完整度评分。
- **共创 / 排行榜 / 成就 / 境界突破**：成长反馈与留存机制。
- 进度持久化于 `localStorage`，刷新不丢；支持水墨 / 像素夜双主题与音效开关。

## 技术

纯静态前端（HTML + CSS + 原生 JS ES Module），Canvas 自绘像素地图，零构建、零依赖。

```
index.html
css/base.css       变量 / 双主题 / 通用组件
css/components.css  各视图与 RPG 样式
js/data.js         全部内容数据（题/典籍/文献/技能/成就/门派/地图）
js/state.js        状态 / 存档 / 资源与境界算法 / 事件总线
js/avatar.js       确定性像素头像生成
js/rpg.js          Canvas 地图引擎（瓦片/移动/碰撞/交互）
js/ui.js           视图 / 导航 / 弹窗 / HUD / 各功能页
js/main.js         入口（存档加载 / 创角 / 启动）
docs/              PRD / DESIGN / DEV
```
